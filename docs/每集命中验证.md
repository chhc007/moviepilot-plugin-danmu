## 关键点

1. **集号正确对应**：`S01E{nn}` 传参后，服务端返回的 `episodeTitle` 集号与请求一致，无错位
2. **主路径用 `/match`**：服务端已做好集号匹配，插件不需要自己解析集号
3. **兜底路径**：若 `/match` 失败，用 `search/episodes?anime={title}` 按 `episodeTitle` 解析集号（注意该接口无 episodeNumber 字段）
4. 弹幕数差异大（国产剧 1.3万+ vs 日番 数百）——是各平台弹幕量本身差异，非匹配问题
