## compose 内容

```yaml
services:
  danmu-api:
    image: logvar/danmu-api:latest
    container_name: danmu-api
    restart: always
    ports:
      - '9321:9321'
    volumes:
      - /vol4/1000/DockerConfig/danmu-api/config:/app/config
      - /vol4/1000/DockerConfig/danmu-api/.cache:/app/.cache
    environment:
      - 'TZ=Asia/Shanghai'
      - 'RATE_LIMIT_MAX_REQUESTS=0'   # 内网自用，关限流
      - 'LIKE_SWITCH=false'           # 不污染弹幕文本
```

## 注意事项

1. **必须挂载 .cache**：episodeId 是进程内自增计数器，不持久化则重启后 ID 全部重新分配，历史 ID 会指向错误剧集
2. **episodeId 不可长期缓存**：插件侧每次刮削现取现用（走 `/api/v2/match`）
3. **`p` 第4段是来源标签**（`[qiyi]`/`[bilibili1]`…），非用户ID
4. 已知 issue #472：episodeId 缓存绑定错位（用「现取现用」规避）
