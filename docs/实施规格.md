## 3. C 方案：danmu_api 数据源（新增 `danmu_api_source.py` 或写在 danmu_generator.py 内）

### 3.1 接口

- **匹配（主入口）**：`POST {BASE}/api/v2/match`，body `{"fileName": "{title} S{ss:02d}E{ee:02d}"}` → `matches[0].episodeId`
- **搜索**：`GET {BASE}/api/v2/search/episodes?anime={title}` → `animes[].episodes[].episodeId`
- **弹幕**：`GET {BASE}/api/v2/comment/{episodeId}?format=json` → `{count, comments:[{p, m}]}`

`BASE` = `{danmu_api_url}` + （token 非空时 `/{token}`），再拼 `/api/v2/...`

### 3.2 必须处理的差异（否则出错）

1. **`p` 第4段是来源标签**（`[qiyi]`/`[bilibili1]`），非用户ID
   - `_is_bili_comment()` 需扩展：判 `bilibili` 子串（兼容 `[bilibili1]`、`[bilibili1&dandan]`）
   - **注意**：不要破坏弹弹play 的 `[BiliBili]` 判定（两者都要认）
2. **animeTitle 被装饰**：`生万物(2025)【国产剧】from iqiyi` → 比对前需剥掉 `\(\d{4}\)`、`【..】`、`from ..`
3. **episodeId 是本地自增计数器**：**不持久化**，每次现取现用
4. **comment 成功响应无 success/errorCode**，直接 `{count, comments}`；404 返回 `{count:0,comments:[]}`
5. **`m` 可能含点赞后缀**：剥掉 `\s*(♡|🔥)[\d.]+[wk]?$`（部署已设 LIKE_SWITCH=false，双保险）
6. **多源并列**：`/match` 已由服务端择优，优先用它；`search/episodes` 只作兜底

### 3.3 集成点（`get_comment_id` / `_generate_danmu_impl`）

```
data_source == "dandanplay":  现有逻辑不变
data_source == "danmu_api":   直接走 danmu_api（跳过整季查询/TMDB）
data_source == "hybrid":      先弹弹play 全套（整季/match/TMDB/B关键词兜底），
                              全失败后再走 danmu_api；若 danmu_api_priority=True 则反序
```

## 4. A 方案：放宽 `/match` 判定（弹弹play，`danmu_generator.py` 约 784 行）

```python
if result.get("matches"):
    if result.get("isMatched"):
        return str(result["matches"][0]["episodeId"])
    picked = cls._pick_match_candidate(result["matches"], file_name, episode)
    if picked:
        logger.info(f"哈希未精确命中，按标题匹配采用候选: {picked}")
        return picked
```

`_pick_match_candidate` 规则：
- 取候选前 10 条
- 标题归一化（小写、去标点/空格/`第N集`/`S01E01`/分辨率/字幕组标签）后比对 `animeTitle`
- 得分：相等 1.0；包含 0.8；否则跳过
- **集号强校验**：候选 `episodeTitle` 能解析出集号时，必须与本地集号一致，否则否决
- 阈值 ≥0.8；**同分歧义 → 放弃**（保守）

## 5. B 方案：关键词搜索兜底（弹弹play）

在 `get_comment_id()` 的 `return None` 之前：
```python
if title:
    cid = DanmuAPI.search_by_keyword(title, episode)
    if cid:
        return cid
```
`search_by_keyword`：`GET /search/anime?keyword={title}` → 归一化标题匹配（精确1.0/包含0.85）→ 同分歧义放弃 → `episodeId = animeId*10000 + 集号`（复用 `_compose_comment_id`）

**需给 `get_comment_id()` / `danmu_generator()` 增加 `title` 参数**，由 `_generate_danmu_impl` 传 `media_info.title`（回退文件名）。
