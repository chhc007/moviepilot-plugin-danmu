# 弹幕匹配改造方案（A+B+C）

> 目标：让各类剧/电影尽可能搜到弹幕
> 基线：`plugins/danmu/` v1.11.0（上游 HankunYu/MoviePilot-Plugins）

## 一、改造总览

| 编号 | 改动 | 解决 | 风险 |
|---|---|---|---|
| **A** | 放宽 `/match` 判定：`isMatched=false` 时用标题相似度校验候选列表 | 日剧（hash 库无记录） | 误匹配 |
| **B** | 关键词搜索兜底：hash/TMDB 都失败时走 `/search/anime` | 日剧 + 部分国创 | 标题歧义 |
| **C** | 新增第二数据源 danmu_api | 国剧/欧美/韩剧/真人电影/综艺 | 新依赖、需部署 |

**匹配管线（改造后）**：
```
手动匹配 → 整季查询 → /match(哈希) → TMDB → 【B: 关键词搜索】 → 【C: 第二数据源】
                └─ 【A: /match 候选校验】插入在第 3 步内部
```

## 二、A：放宽 `/match` 判定

### 现状（`danmu_generator.py` 约 784 行）

```python
if result.get("isMatched") and result.get("matches"):
    return str(result["matches"][0]["episodeId"])
```

`isMatched=false` 时直接放弃，尽管 `matches[0]` 往往就是正确答案。

### 改法

```python
if result.get("matches"):
    if result.get("isMatched"):
        return str(result["matches"][0]["episodeId"])
    # 新增：isMatched=false 时，用标题+集号校验候选
    picked = cls._pick_match_candidate(result["matches"], file_name, episode)
    if picked:
        logger.info(f"哈希未精确命中，按标题匹配采用候选: {picked}")
        return picked
```

### 候选校验策略（防误匹配是关键）

对 `matches` 前 N 条（建议 10）逐一打分，取最高分且过阈值者：

1. **标题归一化**：小写、去标点/空格/常见后缀（`第N集`、`第N话`、`EP`、分辨率、字幕组标签）
2. **animeTitle 比对**：归一化后 相等(1.0) > 包含(0.8) > 不匹配(0)
3. **集号校验**（强约束）：若候选 `episodeTitle` 能解析出集号，必须与本地集号一致；不一致直接否决
4. **阈值**：得分 ≥ 0.8 才采用；多条同分且指向不同作品 → 放弃（保守）

**实测依据**：日剧《非自然死亡》E01 的 `/match` 返回 25 个候选，第 1 条 `{episodeId:306380001, animeTitle:"非自然死亡", episodeTitle:"第1集 无名之毒"}`，标题与集号均可校验通过。

## 三、B：关键词搜索兜底

### 落点

`get_comment_id()` 在 hash 与 TMDB 均失败后、`return None` 之前。

### 改法

```python
# hash 与 TMDB 都未命中，尝试关键词搜索兜底
if title:
    comment_id = DanmuAPI.search_by_keyword(title, episode)
    if comment_id:
        return comment_id
```

### `search_by_keyword` 实现

1. 调 `/search/anime?keyword={title}`
2. 归一化标题匹配：精确(1.0) > 包含(0.8)，取最高分
3. `episodeId = animeId * 10000 + 集号`（复用 `_compose_comment_id`）
4. 候选歧义（多个同分）→ 放弃

### 需要传 title

`get_comment_id` 目前只有 `file_path`。标题来源优先级：
1. `__init__.py` 的 `media_info.title`（MP 识别结果，最准）
2. 文件名解析（`MetaInfo(file_path).name`）
3. NFO 标题

→ 需给 `get_comment_id()` / `danmu_generator()` 增加 `title` 参数，由 `_generate_danmu_impl` 传入。

### 实测依据

关键词搜索命中率：动画/国创/日剧 精确命中（8/8），国创模糊命中（灵笼→"灵笼: INCARNATION"）。

## 四、C：第二数据源 danmu_api

### 背景

弹弹play 不收录国剧/欧美剧/韩剧/真人电影/综艺。danmu_api 支持爱优腾芒B站等 18+ 源。

### 架构：数据源抽象

**现状**：`DanmuAPI` 硬编码唯一源（`BASE_URL`）。

**改造**：抽出源接口，注册多源。

```python
class DanmuSourceBase:
    source_id: str          # "dandanplay" / "danmuapi"
    def search_anime(keyword) -> List[dict]
    def get_comments(episode_id) -> dict
```

- `DandanplaySource`：包装现有 `DanmuAPI`
- `DanmuApiSource`：新实现（接口细节待调研报告）

### 配置项（新增）

- `enable_danmu_api`：开关
- `danmu_api_url`：服务地址（默认官方实例或自建）

### 待调研确认（research-agent 进行中）

- 接口路径/参数/返回结构
- episodeId 编码规则是否与弹弹play 冲突
