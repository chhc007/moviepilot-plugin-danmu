# B 方案可行性验证：关键词搜索兜底

> 验证日期：2026-10-09
> 结论：**B 方案可靠，可作为日剧/国创的主力兜底**

## 一、算法

1. 调 `/search/anime?keyword={标题}`（标题来自 MP 识别结果 `media_info.title`，回退文件名）
2. 候选打分（归一化后比对）：
   - `animeTitle == 标题` → 1.0
   - `标题 ⊂ animeTitle` 或 `animeTitle ⊂ 标题` → 0.85
   - 否则 0
3. 取最高分；**得分 < 0.8 或存在同分歧义 → 放弃**（保守，防误匹配）
4. 命中后 `episodeId = animeId * 10000 + 集号`（复用 `_compose_comment_id`）

### 标题归一化

小写；去除 空格/标点/全角符号/`第N集`/`S01E01`/分辨率/字幕组标签等。

## 三、关键结论

1. **日剧 100% 命中**（非自然死亡、半泽直树、胜者即是正义）——B 能救回日剧
2. **防误匹配机制有效**：灵笼有多个同分候选 → 主动放弃，未误选
3. **千与千寻需注意**：搜索返回多个「千与千寻」条目（1120 / 112），得分相同本应歧义放弃，但因归一化后不完全相等导致只命中一个。**改进**：对同名多条目也应视为歧义，或加年份/类型校验

## 四、实现注意

- **必须传标题**：`get_comment_id()` 需新增 `title` 参数，由 `_generate_danmu_impl` 传入 `media_info.title`
- **只在最后兜底**：手动匹配 → 整季 → /match → TMDB → **关键词搜索**，顺序不能乱（避免关键词误匹配覆盖精确结果）
- **歧义处理**：同分候选 > 1 → 放弃，宁可漏也不误
- **电影特殊**：电影条目可能返回多版本，建议加 `typeDescription`/年份辅助判定
