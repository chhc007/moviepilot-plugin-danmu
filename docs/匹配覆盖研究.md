# 弹幕匹配覆盖研究报告

> 研究日期：2026-10-09
> 目标：确认「各种剧或电影都能搜到弹幕」的可行边界与实现路径
> 测试环境：中转服务 `dandanapi.hankun.online/api/v1`（插件实际依赖），插件 v1.11.0

## 一、核心结论（先看这里）

**弹弹play 的弹幕库以「番剧」为主，这是数据源本身的边界，不是插件 bug。**

| 内容类型 | 收录情况 | 能否拿到弹幕 |
|---|---|---|
| 日本动画（番剧） | ✅ 收录完善 | 能 |
| 国创动画 | ✅ 大部分收录 | 能 |
| 日本电视剧 | ✅ 大部分收录 | 能（但自动匹配有 bug，见第三节） |
| 国产剧 | ❌ 基本不收录 | 不能 |
| 欧美剧 | ❌ 基本不收录 | 不能 |
| 韩剧 | ❌ 基本不收录 | 不能 |
| 真人电影 | ❌ 基本不收录 | 不能 |
| 综艺 | ❌ 基本不收录 | 不能 |
| 动画电影 | ⚠️ 部分收录 | 部分能 |

上游 README 原话（作者已知此边界）：
> 弹弹play 以**番剧弹幕**为主。国产剧、综艺、演唱会、欧美剧、低幼动画等内容通常不在它的收录范围内。
> **这不是匹配失败**，而是对方确实没有这部作品的弹幕数据。对这类文件重复刮削、做手动匹配、调整配置都不会有结果。

### 2.3 弹幕正文接口（`/api/v1/{episodeId}`）

- 规则：`episodeId = animeId * 10000 + 集号`（集号 0..8999，第 0 集是合法特番）
- 实测：日剧《非自然死亡》整季 10 集全部有弹幕，合计 127,783 条（单集 1.2–1.5 万条）
- 单集响应 70–90 秒（数据量大），属正常

## 三、发现的真实缺陷（可优化点）

### 缺陷 1：`/match` 的 `isMatched` 硬门槛过严 ★核心

```python
# danmu_generator.py 约 784 行
if result.get("isMatched") and result.get("matches"):
    return str(result["matches"][0]["episodeId"])
```

实测（日剧《非自然死亡》E01 真实文件指纹）：
```json
{
  "isMatched": false,
  "matches": [ {"episodeId": 306380001, "animeTitle": "非自然死亡", "episodeTitle": "第1集 无名之毒"}, ... 共25个 ]
}
```
- 服务端把候选按相关度排好，**第 1 条就是正确答案**
- 但 `isMatched=false`（无 hash 级精确命中）→ 插件直接放弃，连候选都不看
- **动画**因字幕组版本多、hash 库有精确命中 → `isMatched=true` → 正常
- **日剧**是迅雷下载版，hash 库无记录 → `isMatched=false` → 失败（哪怕候选首条正确）

### 缺陷 2：TMDB 兜底对非动画完全失效

- `/search/tmdb` 仅覆盖动画；日剧/国创即使有数据也返回 EMPTY
- 插件却把 EMPTY 当作权威结论缓存「未收录」（`已记入系列级缓存`），后续不再重试

### 缺陷 3：`/search/tmdb` 返回结构被误用

- 官方 `search/tmdb` 是**关键词搜索**语义；中转服务的 `/search/tmdb` 是**TMDB ID 查询**语义（自建）
- 插件取 `animes[0].episodes[0].episodeId`，对电影类返回异常（千与千寻返回"9集"、你的名字返回"17集"）

## 四、优化方向（待用户决策）

### 方向 A：放宽 `/match` 判定（可解决日剧，收益最大）

在 `isMatched=false` 时，对 `matches` 候选列表做**标题相似度校验**：
- 用文件名/MP 识别的标题 与 候选 `animeTitle`/`episodeTitle` 比对
- 相似度达标（如归一化后相等/包含）才采用，避免误匹配
- 日剧场景：候选首条「非自然死亡」与文件名「非自然死亡」精确匹配 → 可直接采用

**风险**：误匹配（候选首条不对时）。需设严格阈值 + 集号校验。

### 方向 B：增加关键词搜索兜底（可解决日剧+部分国创）

当 hash 与 TMDB 都失败时，用 MP 识别出的标题走 `/search/anime`：
1. 标题归一化（去标点/空格/大小写）
2. 精确匹配优先，其次包含匹配
3. 命中后 `episodeId = animeId * 10000 + 集号`

**实测**：日剧精确命中率高（8/8），国创模糊命中（灵笼→"灵笼: INCARNATION"）。

### 方向 C：修正「未收录」判定（避免错误缓存）

只有「关键词搜索也无结果」才能判定真·未收录；TMDB 返回 EMPTY 不足以定论（对非动画）。

### 无法解决的边界（数据源限制）

国剧/欧美剧/韩剧/真人电影/综艺 —— 弹弹play 就是不收录。除非：
- 换数据源（如 [danmu_api](https://github.com/huangxd-/danmu_api) 支持爱优腾芒B站等 18+ 源）
- 或接入其它弹幕库
